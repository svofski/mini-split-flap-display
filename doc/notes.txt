Encoder sensor
~~~~~~~~~~~~~~
QRE1113 module 8x14.2mm, height ~3mm

Modifications for 5V operation

LED resistor: 330 ohm
collector resistor: 200K (maybe the default 100K is ok)


Split-Flap Controller
~~~~~~~~~~~~~~~~~~~~~
Controller board V1772, 5V MCU CH32V003F4P6

Schematic and notes: https://kyoichisato.github.io/ch32v003-getting-started-ja/V1772.html


Motors
~~~~~~
MG90S 360 degree version


Master MCU
~~~~~~~~~~
Arduino Nano 3 (5V)

Ideally same V1772 if both UART and I2C can be enabled at the same time. Definitely possible with ch32v003fun version, Arduino has too much fat.


Connections
~~~~~~~~~~~

Split-Flap module:

QRE1113 OUT -> CH32 PC4
MG90S PWM   -> CH32 PD3
I2C SDA	    -> CH32 PC1         -> Arduino Nano A4         -> 4K7 pullup to +5V      GREEN or BLUE
I2C SCL     -> CH32 PC2         -> Arduino Nano A5         -> 4K7 pullup to +5V      ORANGE



I2C Communication
~~~~~~~~~~~~~~~~~
Each split-flap display has its own address assigned at build/flashing time. Leftmost is 0x10, second to right is 0x11, etc.


EEPROM
~~~~~~

Reconfigurable parameters:

  - i2c address which must be unique for every display
  - zero mark offset (-4..-2 typically)
  - tracking divider, how fast min/max tracking decays


I2C Commands
~~~~~~~~~~~~

A-Z 0-9 - space	  display character
h                 home
q                 respond with "SFD" [addr] [homing offset] [position] [state] [tracking div]
z [n]             write new homing adjust, signed int8_t
d [n]             write new tracking divider (uint8_t), typically 64..110
a [addr] [~addr]  write new i2c addr, e.g.  0x61 0x11 0xee set addr = 0x11


Master controller (usb serial)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Console commands: 

s               scan the bus, update internal structures and and print info about each display

p TEXT          type text on all units without power budgeting. guarranteed to fail if there are more than 2 units.

h               home all units with power budgeting

t TEXT          type text with power budgeting. text comprises [A-Z0-9\-] to display space use lowercase "h" (home), underscore to skip position

  t HELLO        type HELLO from current position  
  t _____X       update character in position 6 to X
  t h______      home display in position 1

Se              
a addr          assign address. Only valid when there is a single display connected. Necessary when configuring a new module.
  a 0x11	set display i2c address = 0x11

z addr offset   set homing offset
  z 0x11 -3     display at 0x11 homes to position -3

d addr value    set envelope tracking divider (larger value means slower decay)
  d 0x11 110    set device 0x11 to track slower
